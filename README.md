# Learn Yoga Flow Design with Phoebe

Six 45-minute sessions on making a yoga class flow, designing what happens between the poses:
the move as the unit of a sequence, breath as the clock, transitions drawn as stick-figure guides,
a Flow Bench that checks a whole class in the browser, the intensity wave, and adapting a flow live.

- Running case: Rosa, a constructed newly qualified teacher, and her 60-minute Thursday flow at the
  Harbour Room, a constructed community studio.
- Bench: `assets/fb-live.js` with data in `assets/fb-data.js` (generated by
  `materials/build_fb_data.py`). `materials/compare_canon.py` checks the browser engine against the
  Python reference `materials/fb_reference.py` by value.
- Builds on Yoga Theory (the arc of one class, sun salutations, cueing) and Yoga Course Design
  (programmes across weeks); neither is repeated here.
- Not medical advice. Static HTML, no build step: open `index.html`.
